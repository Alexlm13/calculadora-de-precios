Módulo calculadora¶

Calculadora de precios.

Este módulo permite calcular el precio de un producto con IVA, aplicar un descuento y obtener el precio final aplicando ambos. El descuento se aplica siempre sobre el precio base y el IVA sobre el precio ya descontado.

Uso desde la línea de comandos:

python calculadora.py 100 --descuento 10 --iva 21

Funciones principales:

  • calcular_precio_con_iva()

  • aplicar_descuento()

  • calcular_precio_final()

calculadora.IVA_GENERAL = 21.0¶

Porcentaje de IVA general que se aplica por defecto (21 %).

calculadora.aplicar_descuento(precio, descuento)[fuente]¶

Aplica un descuento porcentual a un precio.

Parámetros:

  • precio (float) – Precio original. Debe ser mayor o igual que 0.

  • descuento (float) – Porcentaje de descuento, entre 0 y 100.

Devuelve:

Precio tras el descuento, redondeado a dos decimales.

Tipo del valor devuelto:

float

Muestra:

ValueError – Si el precio es negativo o el descuento no está entre 0 y 100.

Ejemplo

>>> aplicar_descuento(200, 25)
150.0
>>> aplicar_descuento(80, 0)
80.0
calculadora.calcular_precio_con_iva(precio, iva=21.0)[fuente]¶

Calcula el precio de un producto incluyendo el IVA.

Parámetros:

  • precio (float) – Precio base sin IVA. Debe ser mayor o igual que 0.

  • iva (float) – Porcentaje de IVA a aplicar. Por defecto 21.

Devuelve:

Precio con IVA, redondeado a dos decimales.

Tipo del valor devuelto:

float

Muestra:

ValueError – Si el precio o el IVA son negativos.

Ejemplo

>>> calcular_precio_con_iva(100)
121.0
>>> calcular_precio_con_iva(50, iva=10)
55.0
calculadora.calcular_precio_final(precio, descuento=0.0, iva=21.0)[fuente]¶

Calcula el precio final aplicando primero el descuento y luego el IVA.

Parámetros:

  • precio (float) – Precio base sin IVA. Debe ser mayor o igual que 0.

  • descuento (float) – Porcentaje de descuento, entre 0 y 100. Por defecto 0 (sin descuento).

  • iva (float) – Porcentaje de IVA a aplicar. Por defecto 21.

Devuelve:

Precio final, redondeado a dos decimales.

Tipo del valor devuelto:

float

Muestra:

ValueError – Si algún parámetro está fuera de su rango válido.

Ejemplo

>>> calcular_precio_final(100, descuento=10, iva=21)
108.9
>>> calcular_precio_final(100)
121.0
calculadora.main(argumentos=None)[fuente]¶

Ejecuta la calculadora desde la línea de comandos.

Parámetros:

argumentos (list[str] | None) – Lista de argumentos. Si es None se leen de sys.argv.

Devuelve:

0 si todo ha ido bien y 1 si algún dato no es válido.

Tipo del valor devuelto:

int
