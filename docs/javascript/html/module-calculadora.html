Module: calculadora

Calculadora de precios. Permite calcular el precio de un producto con IVA, aplicar un descuento y obtener el precio final aplicando ambos. El descuento se aplica siempre sobre el precio base y el IVA sobre el precio ya descontado. Uso desde la línea de comandos: node calculadora.js 100 --descuento 10 --iva 21
